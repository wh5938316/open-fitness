# Commit messages

Use English Conventional Commits:

```text
type(optional-scope): imperative summary
```

Use `feat`, `fix`, `docs`, `test`, `refactor`, `build`, `ci`, or `chore`. Keep the subject specific and concise. Explain meaningful reasons or compatibility changes in the body; do not claim tests that were not run.

Examples:

```text
feat(recipes): reuse saved nutrition snapshots when logging meals
fix(auth): reject an authorization transaction after its first use
test(training): verify completed workout corrections preserve planned targets
docs: explain passkey recovery for self-hosted instances
```
